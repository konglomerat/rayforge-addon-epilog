# Banner typography

The README banner uses D-DIN Bold and D-DIN Regular, a DIN-family typeface.
The unmodified font files come from
[Datto D-DIN](https://github.com/amcchord/datto-d-din).

The fonts are licensed under the [SIL Open Font License 1.1](OFL-1.1.txt).
The SVG banner contains outlined lettering so it renders consistently
without installing fonts. Its PNG export is used in the README.
